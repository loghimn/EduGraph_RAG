# Machine Learning Basics

Machine learning is a subfield of artificial intelligence (AI). 
It focuses on the development of algorithms that allow computers to learn from and make predictions based on data.

## Supervised Learning
In supervised learning, the model is trained on labeled data. 
One of the most common algorithms is Support Vector Machine (SVM).
Support Vector Machines are used for classification tasks.

Another important algorithm is Gradient Descent, which is used to minimize the loss function.
We should not confuse gradient descent with simple gradient calculation.
The derivative of a function measures its sensitivity to change.

## Formulas
Here is a formula for linear regression:
$$ y = wx + b $$
This allows us to fit a straight line to the data.
